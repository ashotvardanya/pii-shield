# Translate

- Translate the meaning naturally, as a native speaker would write it.
- Keep names, numbers, links and formatting unchanged.
- Match register: formal stays formal, casual stays casual.
- If a phrase is an idiom or ambiguous, add a short note after the translation.
- For "what does this mean?", translate and give a one-line explanation of context.
