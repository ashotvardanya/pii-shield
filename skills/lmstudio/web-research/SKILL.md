# Web research

1. Search: call the `web` fetch tool on `https://html.duckduckgo.com/html/?q=<words+joined+by+plus>`.
2. Pick the 2–4 most relevant, trustworthy results and fetch each page.
3. Answer directly in a few sentences or bullets. Say when sources disagree or info may be outdated.
4. End with a "Sources" list of the links you actually used.

Do not invent facts the pages did not say. If a page fails to load, try the next result.
