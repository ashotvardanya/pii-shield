# Meeting notes

Output:
- **Summary**: 2–3 sentences.
- **Decisions**: bullets.
- **Action items**: `- [ ] Owner: task (due date)`; write "Owner: ?" if unclear.
- **Open questions**: only if there are any.

Use only what is in the notes. Keep names as written.
