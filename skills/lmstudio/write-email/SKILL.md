# Write email

- Ask nothing unless the goal is truly unclear; make sensible assumptions and draft.
- Give a subject line (for emails), then the message.
- Match the tone asked for; default is friendly, clear and short. Firm but polite for complaints.
- Lead with the point, one idea per paragraph, a clear ask or next step at the end.
- No filler ("I hope this email finds you well") unless the user wants formal style.
- Offer one shorter or more formal variant only if it would help.
