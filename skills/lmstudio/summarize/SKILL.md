# Summarize

Read the whole thing first (use the `files` tool for a path, the `web` tool for a link).

Format:
- **TL;DR**: one or two sentences.
- **Key points**: 3–7 bullets, most important first.
- **Action items / deadlines / numbers**: only if the text has any.

Keep the author's meaning; don't add opinions. Quote exact figures and dates. If the user asks
for a length (e.g. "in 3 bullets"), follow it.
