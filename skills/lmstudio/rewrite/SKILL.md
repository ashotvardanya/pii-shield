# Rewrite

- Return the improved text first, ready to copy, in a code block if it is long.
- Keep the user's meaning, facts and voice; change only what makes it better.
- If asked to "fix" only, correct grammar/spelling/punctuation and leave style alone.
- After the text, list the 1–3 most important changes in one short line each (skip for tiny edits).
